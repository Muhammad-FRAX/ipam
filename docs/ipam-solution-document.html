Architecture & Edge Enforcement

PostgreSQL CIDR Overlap Casting

Unlike rigid string-matching tools, the Phase 1 Validations Engine harnesses deep native PostgreSQL operators for mathematical overlap checks. By actively casting incoming strings to `CIDR` types, the system performs binary-level evaluations before data is ever persisted.

// Native Overlap Query Validation
SELECT id, name, cidr
FROM subnets
WHERE CAST(cidr AS CIDR) && CAST($1 AS CIDR)

API Gateway Routing

The frontend portal never communicates directly with individual microservices. All interactions cross through a centralized NestJS `http-proxy-middleware` API Gateway configured to rewrite `/api/*` structures into specific Docker DNS mapped service ports, ensuring internal service obfuscation.

Centralized Audit Logging

The `audit-service` maintains an immutable operational ledger. Every structural mutation (block creation, IP allocation, Request approval, System export) is asynchronously shipped to the Audit Engine.

Records retain the action `type` (e.g., EXPORT, ALLOCATE), targeted `entity_id`, initiating `user_id`, precise `timestamp`, and the complete JSON snapshot of the state details. This ensures complete multi-tenant tracking capabilities.

Multi-Format Compliance Exports

Under the Forecasting & Insight Service, a dedicated structural export engine compiles real-time database snapshots into compliance-ready formats.

  • PDF Document Generation

    Generates structured managerial reports with timestamps, scope bounds, and truncated visual lists using PDFKit.

  • Excel Virtual Workbooks

    Multi-tabbed `.xlsx` exports automatically arranging hierarchical blocks and cascading IP allocations via ExcelJS.
